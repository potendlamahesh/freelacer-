# freelance.maheshp.in

Portfolio website of Mahesh Potendla. Plain HTML, CSS and JavaScript, no build step.

## Structure

```
index.html          page
css/style.css       styles
js/main.js          navigation, scroll effects, contact form
assets/images/      project screenshots and profile photo
404.html            not found page
CNAME               custom domain for GitHub Pages
robots.txt          crawler rules
sitemap.xml         sitemap
```

## Hosting

Served with GitHub Pages from the root of the main branch, on the custom domain in `CNAME`.
